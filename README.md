
## 主要模块

| 模块 | 说明 | 负责人 |

## 协议帧格式（20 字节 PDU）

| 字段 | 长度 | 说明 |
|------|------|------|
| magic | 1 字节 | 固定 0xDB |
| hop | 1 字节 | TTL，递减到 0 停止转发 |
| flag | 1 字节 | 加密标志等 |
| index | 1 字节 | 序号，用于去重 / 防重放 |
| src | 1 字节 | 源地址 |
| dst | 1 字节 | 目的地址 |
| element ID | 1 字节 | 要素标识 |
| appdata | 12 字节 | TLV 格式 |

## selfsec 加密模块

- 标准 AES 分组为 16 字节，只考虑单包实现功能，并且单包需要放入广播包，NUS包，所以长度受限，另外也是为了检验学习，所以没有使用标准AES算法。
- 裁剪为 **4 字节 block**，复用 AES 的 S-box 和密钥扩展逻辑，减少轮数。
- 仅提供机密性，没有完整性 / 认证。
- IV 固定为 0，相同明文产生相同密文。
- 定位：在字节约束下做基本混淆，不是强加密。

## 已知限制

- 非标准蓝牙 Mesh，无 provisioning、无安全配对。
- selfsec 安全强度弱于标准 AES，仅用于教学演示。
- 当前 build 中 APPKEY / NETKEY 加密可能被注释，用于调试转发路径。
