# selfmesh

## 项目说明

本项目是一个基于 **nRF52832 / PCA10040** 的 BLE 广播轻量级自组织网络学习项目，用于理解自组织网络与加密原理。  
它不是蓝牙 SIG 标准 Mesh，而是基于 BLE 非连接广播（ADV_NONCONN_IND）的简化实现，仅供教学演示。

## 贡献说明

本项目为家庭学习项目，家长提供底层框架与硬件调试指导，本人负责应用层协议与加密模块。具体分工如下：

- **家长**：nRF52832 底层驱动、BLE 广播/扫描调度、转发与去重、硬件调试指导。
- **本人**：应用层 PDU 格式设计、TLV 字段定义；selfsec 轻量加密模块实现；参与转发与去重逻辑的调试与验证。
- **README**：在 AI 辅助下整理，技术细节经本人核对，家长贡献部分已标注。

## 主要模块

| 模块 | 说明 | 负责人 |
|------|------|--------|
| 应用层 PDU | 定义承载格式，用于多跳转发与去重 | 本人 |
| TLV appdata | 12 字节，tag 分三段：网络管理 / 要素管理 / 应用服务 | 本人 |
| selfsec | 轻量加密模块，4 字节 block，复用 AES S-box 与密钥扩展 | 本人 |
| 转发与去重 | 根据 hop、index、dst 决定是否转发 | 家长框架，本人参与调试 |
| BLE 广播/扫描 | 非连接广播发送与扫描调度 | 家长 |
| 硬件与 SDK | nRF52832 / PCA10040，nRF5 SDK | 家长 |

## 协议帧格式（PDU）

| 字段 | 长度 | 说明 |
|------|------|------|
| magic | 1 字节 | 固定 0xDB |
| hop | 4 bit | TTL，递减到 0 停止转发 |
| flag | 4 bit | bit0 控制应用加密，bit1 控制网络加密，bit2 和 bit3 预留 |
| index | 1 字节 | 序号，用于去重 / 防重放 |
| src | 2 字节 | 源地址 |
| dst | 2 字节 | 目的地址 |
| element ID | 1 字节 | 要素标识，当前支持 4 个要素：可分别指定，也可同时指定所有要素 |
| appdata | 12 字节 | TLV 格式 |

合计：20 字节（hop 与 flag 共占 1 字节）。

## selfsec 加密模块

标准 AES 分组为 16 字节，而 BLE 广播包有效载荷仅 31 字节，单包需承载完整 PDU，无法容纳标准 AES 的填充与 IV 开销。本模块定位为学习用途，因此没有直接使用标准 AES，而是裁剪为 **4 字节 block**，复用 AES 的 S-box 与密钥扩展逻辑，减少轮数至8轮。

- 仅提供机密性，没有完整性 / 认证（无 MAC）。
- IV 固定为 0，相同明文产生相同密文。固定 IV 是为了在 31 字节广播包内省去 IV 传输开销；**教学上需指出这是弱点**。
- 定位：在字节约束下做基本混淆，不是强加密。

## 已知限制

- 非标准蓝牙 Mesh，无 provisioning、无安全配对。
- selfsec 安全强度弱于标准 AES，仅用于教学演示。
- 当前 build 未启用 APPKEY 加密，仅使用 NETKEY 加密。

## 构建与运行

开发工具使用 Segger Embedded Studio（SES），基于 Nordic nRF5 SDK 和 nRF52832 开发板。
